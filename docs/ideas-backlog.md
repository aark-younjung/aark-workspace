## 💡 WordPress 插件化（2026-06-09 加入）

**來源：** 第一位付費客戶 yuppy0912 反饋「修網站時要在原網站和 Aark 來回切換很煩」、進而建議「能不能做 WordPress 外掛、像 Yoast / Rank Math 那樣裝在 WP 後台、順便做全世界 WP 用戶的生意」。

### 戰略價值（為何值得認真想）

| 槓桿 | 對 Aark 的具體效益 |
|---|---|
| 70M WP 站的分發通路 | wordpress.org 是世界最大免費獲客來源、抓 0.01% = 7,000 站 |
| 零摩擦入門 | 30 秒裝完、不用註冊網站、Free 版直接體驗 → Pro 漏斗自然 |
| 黏著度暴增 | 插件活在每天的 WP 後台、留存遠勝獨立 web tool |
| 修復一鍵化 | 從「告訴你紅燈」升級為「一鍵自動套 Schema / llms.txt」、徹底解客戶切換痛點 |
| 戰略卡位 | Yoast / Rank Math 還沒做 LLMO、拿下「LLMO 之於 WP」這個 niche、後續難被超車 |
| 跨平台複製 | 走通後可複製到 Shopify App Store / Wix App Market / Webflow Apps |

### 隱性成本（為何不能輕率上馬）

| 成本項 | 嚴重度 |
|---|---|
| **PHP / WP 技術棧不同** | 現在 React/Vite stack、寫真實 WP 插件要 PHP + Hooks + REST API、不同技能 |
| **WordPress.org 審核** | GPL 開源、安全審核嚴格、首次送審 2-4 週、被退回常見 |
| **付費版要拆兩個插件** | 慣例：免費 + Premium 各一個 plugin、維護複雜度 ×2 |
| **Yoast / Rank Math 共存** | 用戶通常已有 SEO 外掛、要當補位非取代、相容性測試成本 |
| **i18n（國際化）** | 全球發行要多語、現在所有 UI / 文案是中文、要全 extract 成翻譯字串 |
| **兩個產品同步維護** | Web app + WP plugin、功能漸漸分歧、技術債翻倍 |

### 兩條實際路線

**路線 A — 薄殼插件（驗證用、1 個月）**
- iframe / API 嵌 Aark dashboard 進 wp-admin
- 全部分析跑在 Aark 後端
- 加 1 個殺手功能：「一鍵注入 Schema」（PHP 直接寫 head、免裝 WPCode）
- 目的：驗證需求、收 1-2 個月用戶數據

**路線 B — 原生 WP 插件（押大注、3-6 個月）**
- 完整 PHP 重寫 5 訊號層分析、本地跑（更快、無 API 依賴）
- 完整 wp-admin UI / 儀表板 / 修復面板
- 全部 fix 一鍵自動套（Schema / llms.txt / robots.txt / meta）
- API 只留給 aivis 跨 LLM 監測（無法本地做）
- 定位：「Yoast Killer for LLMO」、Pro 訂閱核心鉤子

### 決定前要回答的 3 個問題

1. **P0 是代理商還是 WP 站主？**
   - 代理商不一定能在客戶 WP 裝外掛（需客戶授權）
   - WP 站主才是直接受益者
   - 影響插件設計優先順序
2. **有 PHP / WP 開發者嗎？**
   - 現在 React/Vite stack
   - 要不要外包 / 找新人 / 學新技能、影響估時
3. **準備好做英文版嗎？**
   - 全球發行最大門檻不是技術、是 i18n + 英文 marketing copy + 客服

### 暫定結論（2026-06-09）

**目前不啟動、原因：**
- 上線阻擋未除（公告文案 + 客服通道）、應先把現有產品穩定起來
- 沒有真實使用數據、不知道「跨網站切換」是不是真痛點還是 anecdote
- P0 是代理商、代理商在客戶 WP 裝外掛的場景有限

**何時重新評估：**
- 上線後 1-2 個月、有 20+ 真實付費代理商 / 站主使用
- 看實際反饋裡「我想要 WP 插件」的呼聲有多大
- 同時看 Agency 多客戶工作區的 ROI 是不是更高

**如果決定做、最務實的開始：**
路線 A 薄殼版、聚焦「一鍵注入 Schema」這個殺手功能、1 個月驗證需求、再決定要不要押路線 B。
