## A. 全域（跨區塊）

| 項目 | 級 | 說明 |
|---|---|---|
| 舊 URL 1:1 轉址 ＋ 導覽接入 `/app` | 🔴 | ＝上線動作本身。`/dashboard/:id`、四大 audit、content、aivis 深連結全對應，不可全導總覽 |
| 三個小 polish | 🔴 | ①站名缺失時用 hostname 呈現 ②站卡 aivis 分數接共用聚合 ③額度分母依方案（150/試用上限）不寫死 |
| **指標詞彙表／「我們如何衡量」卡** | 🔴 | 純文案工程。每個分數旁「這個數字量什麼、為什麼跟另一個分數不一致」——多分數產品的信任地基（Kuroma 實測學來） |
| **Pro 鎖定頁改「模糊真實樣板＋浮標」** | 🟠 | 取代純 🔒 頁。模糊化的樣板資料＋「升級解鎖」浮標，好奇心轉化強得多 |
| **BETA / NEW / Pro 徽章系統** | 🟠 | 選單與卡片統一徽章（管理功能預期、標新功能）；改版元件層一次做 |
| 大數字卡三層結構 | 🟠 | 每張 KPI 卡：數字（大）→ 脈絡（「在 N 個同類中第 3」/「比上次 +5」）→ 行動連結。AppOverview/Visibility 現有卡補第二三層 |
| 每頁一句人話摘要 | 🟡 | 頁首副標從「功能名」升級成「您的成績單：在最關鍵的問題上，您是如何被發現的」式人話 |
| 淺色「可列印」報告模式 | 🟡 | 亮色版天然適合；補 `@media print` 樣式＝代理商拿報告給客戶的白標前哨 |
| 已繼承（不用再做） | ✅ | 頁型判斷 N/A、站台層複查、快取新鮮度提示、Meta 分語言、真 delta、空狀態全有 CTA（AGENTS §0.1/§2 已鎖） |

## C. AI 曝光監測（AppVisibility）

| 項目 | 級 | 說明 |
|---|---|---|
| **引用來源萃取（共識 P1-1）** | 🟠 | 從既有 aivis 回答解析：①「同類領先者」卡接真資料（現 placeholder）②「誰在影響 AI 對你的描述」來源清單 ③AI 還推薦了誰（mention share）。零額外 API 成本。誠實線：標「AI 回答中實際出現的品牌/來源」、非猜測 |
| **AI 講錯你（事實監測台灣版，共識 P1-2）** | 🟠 | 比對 raw_response vs 品牌事實（電話/地址/營業時間/服務範圍），列「AI 講錯清單」→ 接修復側：產修正 JSON-LD、外掛路線直接寫進網站（Kuroma 做不到的一步） |
| **sentiment 觀感輕量版（共識 P2-1）** | 🟡 | 離線標註既存回答（正/中/負）＋「每引擎一句 AI 原話」摘引 |
| 「基準題組」呈現化 | 🟡 | UI 把 core/rotating 雙軌講出來：「固定題組、每次重跑、趨勢可比」——回應「自己問 AI 就好」的話術載體（功能已有、只差呈現） |
| 競爭矩陣紅綠格＋紅綠對比卡 | 🟡 | 引用萃取做完後：領先標綠/落後標紅；「縮小差距」紅卡＋「你的優勢」綠卡 |
| 品牌檔案完整度進度條 | 🟡 | aivis 品牌資料（網域/產業/UVP…）填寫度進度條→資料越全掃描越準、順手收資料 |
| 表內警示 tag | ⚪ | 引用來源表內嵌「疑似內容農場」類黃標（需來源分類邏輯，跟引用萃取一起評） |
